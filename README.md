# Kompanikamratföreningen

Bordshäftet och presentationerna till 333. Hemvärnsinsatskompaniets kompanimiddag.

## Sidor

| Sida | Länk | Anmärkning |
|---|---|---|
| Bordshäftet | [henkegyllen.github.io/Kompanikamratforening](https://henkegyllen.github.io/Kompanikamratforening/) | Det gästerna öppnar via QR-koden |
| Från soldat till hemvärnet, mobil | [presentation.html](https://henkegyllen.github.io/Kompanikamratforening/presentation.html) | Länkas från bordshäftet |
| Från soldat till hemvärnet, fullskärm | [fullskarm.html](https://henkegyllen.github.io/Kompanikamratforening/fullskarm.html) | För storbild. Bild 0 väljer soldat |
| Kajsas tal | [kajsas-tal/](https://henkegyllen.github.io/Kompanikamratforening/kajsas-tal/) | Fullskärm, tryck F |
| Sök i FAL-A | [sok.html](https://henkegyllen.github.io/Kompanikamratforening/sok.html) | Låst tills `data-visa="1"` står överst i filen |

## Filer

- `org.js` – organisationsmodellen (bataljoner, kompanier, plutoner, anrop). Delas av `presentation.html`, `fullskarm.html` och `sok.html`.
- Bygger på öppna källor och antaganden. Inte ett officiellt dokument.
